1

Đăng nhập tài khoản

2

3

Phân rã Subtasks & Soạn thảo tài liệu

Xếp lịch, Kéo thả & Theo dõi tiến độ

Cấu hình Firebase & Cloud Sync

Để kích hoạt tính năng Đăng nhập Google, Lưu trữ Google Drive và Đồng bộ Multi-tenant Đám mây, hãy dán đoạn mã cấu hình Firebase (Project Settings → General → SDK setup and configuration):

Hướng dẫn nhanh trong 2 phút:
1. Truy cập console.firebase.google.com → Tạo project miễn phí.
2. Vào Authentication → Bật Google Sign-In.
3. Vào Firestore Database → Bấm Tạo Database (chọn chế độ test).
4. Copy object firebaseConfig dán vào ô bên dưới.

Cài đặt Email nhắc việc

Hệ thống tự động chạy ngầm qua GitHub Actions để gửi email nhắc nhở vào buổi sáng và tổng kết vào buổi tối (múi giờ Việt Nam). Ngày nào không có task sẽ thông báo ngày nghỉ thảnh thơi.

Chưa đăng nhập
Hướng dẫn cấu hình GitHub Secrets (Chỉ làm 1 lần)
Vào repository GitHub → Settings → Secrets and variables → Actions → Thêm 3 Secrets sau:
1. FIREBASE_SERVICE_ACCOUNT: File JSON Private Key lấy từ Firebase Console (Project Settings → Service accounts → Generate new private key).
2. GMAIL_USER: Địa chỉ Gmail của bạn (dùng làm hộp thư gửi).
3. GMAIL_APP_PASSWORD: Mật khẩu ứng dụng 16 chữ số tạo từ Google Account (Bảo mật → Xác minh 2 bước → Mật khẩu ứng dụng).
